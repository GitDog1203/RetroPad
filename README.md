# RetroPad

My 1st Hackpad!



Buttons: 

Up, Down, Left, Right, for movement

A, B, for selection

Other features:

Case to hold PCB

Screen for a small display.



Parts:

1x Seeed Xiao RP2040

6x MX-Style switches

1x 0.91 inch OLED display

4x M3x16mm screws

4x M3x5mx4mm heatset inserts

4x white blank DSA Keycaps
