# RetroPad

A custom 6-button macropad built with a Seeed XIAO RP2040.

## Hardware

- Controller: Seeed XIAO RP2040
- Layout: 2 rows × 3 columns
- Switches: 6 buttons with matrix diodes

## Keymap

The default keymap will provide directional buttons and A/B action buttons.

## Firmware

This keyboard uses QMK Firmware.
